PROJECT DESCRIPTION

PROJECT NAME : Market Expansion & Lead Prioritisation

CREATED BY : ANIMESH DUTTA


PROJECT BRIEFING

Engineered a B2B Market Segmentation Pipeline: Processed legacy corporate transaction datasets in Python to construct a K-Means clustering model; isolated high-velocity enterprise client profiles into a dedicated "Ideal Customer Profile" (ICP) segment representing the company's highest-value targets.
Optimised Enterprise Lead Prioritisation Engine: Developed a Random Forest Classifier to predict contract sizes, mitigating a severe 8% data class imbalance by applying balanced class weights and adjusting the predictive activation threshold down to 25%; increased large-deal catch velocity (Recall) from 17% to 39% to prevent high-value revenue leakage.
Designed Data-Driven Go-To-Market Strategy: Formulated an operational Business Requirements Document (BRD) and deployed an interactive tracking dashboard; established a Pareto-aligned (80/20) resource allocation playbook directing sales capital toward top-tier accounts while instating a 90-day dynamic recalibration trigger to capture emerging run-rate growth.
